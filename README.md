# منصة نور — NOOR
### منصة قرآنية عالمية متكاملة ومجانية لوجه الله تعالى

تطبيق **نور (NOOR)** هو منصة قرآنية وإسلامية رقمية متطورة ومجانية بالكامل، خالية من أي إعلانات أو اشتراكات، مصممة وفق أحدث معايير هندسة البرمجيات وتصميم واجهات المستخدم (Material Design 3) لتقديم تجربة إيمانية استثنائية لقراءة القرآن الكريم والاستماع لكبار القراء وتدبر الآيات وحفظها.

---

## 🌟 الميزات الأساسية المنفذة

1. **الصفحة الرئيسية (Home)**:
   - واجهة إسلامية فاخرة بهوية الزمرد الداكن والذهب العتيق والعاجي المريح.
   - تحية مباركة وتاريخ هجري وتوقيت الصلاة القادمة مع عداد تنازلي دقيق.
   - بطاقة متابعة القراءة السريعة التي تحتفظ تلقائياً بآخر سورة وآية وصفحة.
   - متابعة الورد اليومي (صفحات اليوم) ونسبة إنجاز خطة الحفظ (أيام متتالية Streak 🔥).
   - شبكة الوصول السريع لجميع أبواب التطبيق.
   - آية اليوم وتدبرها مع تسبيحة سريعة تفاعلية.

2. **المصحف الشريف (Quran Reader)**:
   - **الرسم العثماني الأصيل**: خط قرآني عالي الدقة (Amiri) متوافق مع مصحف المدينة النبوية مع علامات الوقف والضبط.
   - **نمطان متقدمان للقراءة**:
     - **نمط مصحف المدينة الرقمي**: تصفح صفحات المصحف الشريف الـ 604 مع الإطار الإسلامي وزخارف رأس السورة ورقم الجزء والصفحة.
     - **نمط القراءة التفاعلي المرن**: تصفح آية بآية مع شريط أدوات سريع عند النقر (استماع، تفسير ميسر، إضافة للعلامات، نسخ، مشاركة).
   - إمكانية تكبير وتصغير حجم الخط بسلاسة (18sp - 38sp).
   - حفظ تلقائي لآخر موضع قراءة في قاعدة بيانات Room المحلية.

3. **فهرس القرآن الكريم (Index)**:
   - فهرس السور الـ 114 كاملة مع بيان المكية والمدنية وعدد الآيات ورقم الصفحة وترتيب النزول.
   - فهرس الأجزاء الـ 30 مع بداية كل جزء ورقم صفحته.
   - سجل العلامات المرجعية (Bookmarks) مع إمكانية الحفظ والحذف والانتقال المباشر للآية.
   - شريط تصفية وبحث سريع في أسماء وأرقام السور.

4. **البحث القرآني الذكي (Quran Search)**:
   - محرك بحث عربي فوري يدعم البحث بالرسم الإملائي والعثماني مع تطبيع التشكيل (Tashkeel Normalization).
   - كلمات شائعة واقتراحات بحث جاهزة (الله، الرحمن، الصبر، الجنة...).
   - إمكانية الانتقال المباشر من نتيجة البحث إلى موضع الآية في المصحف.

5. **مشغل التلاوات الصوتية المتكامل (Audio Reciter Player)**:
   - كبار قراء العالم الإسلامي عبر بث حي موثوق (EveryAyah / Mp3Quran):
     - الشيخ مشاري راشد العفاسي
     - الشيخ عبد الباسط عبد الصمد (المرتل)
     - الشيخ محمود خليل الحصري (المرتل)
     - الشيخ سعد الغامدي
     - الشيخ ماهر المعيقلي
   - شريط تحكم مصغر (Mini Player) يرافق المستخدم في جميع شاشات التطبيق.
   - تكرار الآية للحفظ (1x, 3x, 5x, مستمر).
   - مؤقت النوم (Sleep Timer) لإيقاف التلاوة تلقائياً بعد مدة محددة.
   - تشغيل متتابع للآيات والسور.

6. **التفسير ومعاني الكلمات والتدبر (Tafsir & Vocab)**:
   - التفسير الميسر الموثوق لكل آية كريمة.
   - شرح المفردات والكلمات الغريبة في سياق الآية.
   - فوائد إيمانية ولفتات تدبرية تعين القارئ على العمل بكتاب الله.
   - إمكانية نسخ ومشاركة بطاقة الآية وتفسيرها.

7. **الحفظ والمراجعة ووضع التسميع الذاتي (Memorization)**:
   - إنشاء ومتابعة خطط الحفظ لسور القرآن الكريم.
   - شريط نسبة الإتقان ومعدل المراجعات لكل سورة.
   - **وضع التسميع الذاتي (Self-Testing Mode)**: إخفاء الآيات لحث المستخدم على التلاوة غيباً، مع خاصية النقر للكشف والتحقق من صحة القراءة.

8. **الأذكار والأدعية والسبحة الرقمية (Athkar & Digital Tasbih)**:
   - أذكار الصباح والمساء، أذكار بعد الصلاة، أذكار النوم والاستيقاظ، وأدعية قرآنية مأثورة.
   - عداد تفاعلي لكل ذكر مع بيان الفضل والمصدر من الصحاح.
   - **سبحة رقمية حرة (Digital Tasbih)** مع دائرة نقر كبيرة، اهتزاز تفاعلي (Haptic Feedback)، وصيغ تسبيح مأثورة وأهداف محددة.

9. **مواقيت الصلاة وبوصلة القبلة (Prayer Times & Qibla)**:
   - حساب دقيق للمواقيت (الفجر، الشروق، الظهر، العصر، المغرب، العشاء) بحسب المعادلة الفلكية الدقيقة لمدن العالم الإسلامي.
   - بوصلة قبلة تفاعلية حية تقيس زاوية اتجاه الكعبة المشرفة في مكة المكرمة باستخدام مستشعرات الجهاز الحقيقية (Rotation Vector / Compass) مع مؤشر المحاذاة.

10. **الإعدادات واللغات وإدارة التنزيلات (Settings & Downloads)**:
    - تخصيص الخطوط والأنماط والألوان.
    - إدارة المحتوى دون اتصال (Offline Storage) ومسح الذاكرة المؤقتة.
    - دعم حقيقي وكامل للاتجاه من اليمين لليسار (RTL) بالعربية كلغة أساسية.

11. **الملف الشخصي وإحصائيات القراءة (Profile & Khatma)**:
    - متابعة الختمات، الآيات المقروءة، الأيام المتتالية، وتصدير نسخة احتياطية من العلامات.

## 🏛️ البنية المعمارية والتقنية

- **لغة البرمجة**: Kotlin بالكامل.
- **إصدار Java**: Java 21 LTS (Temurin).
- **واجهة المستخدم**: Jetpack Compose مع Material Design 3.
- **معمارية الكود**: MVVM (Model-View-ViewModel) مع Clean Architecture و Repository Pattern.
- **التخزين المحلي**: Android Jetpack Room Database مع KSP و SQLite لحفظ العلامات والتقدم وخطط الحفظ دون إنترنت.
- **المعالجة غير المتزامنة**: Kotlin Coroutines & StateFlow.
- **الخطوط المدمجة محلياً**: Google Fonts (Amiri للآيات، Cairo للواجهات) عبر أداة `font-util`.
- **أيقونة التطبيق**: Adaptive Launcher Icon فاخرة بشعار نور الذهبي والزمردي متوافقة مع جميع أحجام الشاشات.

## 🚀 سير العمل في GitHub Actions (`ci.yml`)

يتضمن المشروع ملف أتمتة متكامل في المسار:
`.github/workflows/ci.yml`

يقوم سير العمل تلقائياً عند كل `push` أو `pull_request` بالآتي:
1. التحقق من سلامة Gradle Wrapper (`wrapper-validation`).
2. إعداد بيئة Java 21 (Temurin) وتفعيل التخزين المؤقت لـ Gradle.
3. تجهيز ملف البيئة `.env` ومفتاح التوقيع التجريبي `debug.keystore`.
4. تشغيل جميع اختبارات الـ Unit Tests واختبارات Robolectric (`./gradlew testDebugUnitTest`).
5. رفع تقارير نتائج الاختبارات بصيغة HTML كـ Artifacts.
6. بناء حزمة التطبيق التجريبية (`./gradlew assembleDebug`).
7. رفع ملف التطبيق الناتج (`app-debug.apk`) كـ Artifact صالح للتنزيل والتجربة المباشرة.

## 💻 التشغيل المحلي وبناء المشروع

### 1. استنساخ المشروع:
```bash
git clone https://github.com/USERNAME/noor-quran.git
cd noor-quran
```

### 2. تجهيز ملف البيئة:
```bash
cp .env.example .env
```

### 3. تشغيل الاختبارات الآلية (Robolectric & Unit Tests):
```bash
./gradlew testDebugUnitTest
```

### 4. بناء نسخة التجربة (Debug APK):
```bash
./gradlew assembleDebug
```
يتم إنشاء ملف الـ APK داخل المسار:
`app/build/outputs/apk/debug/app-debug.apk`

## 🔐 إعدادات الأسرار (GitHub Secrets)

المنصة مصممة لتعمل ذاتياً بالكامل محلياً وبثبات تام دون أي مفاتيح خارجية إلزامية.
إذا أردت في المستقبل بناء وتوقيع نسخة الإصدار النهائي (Release APK/AAB) للنشر على Google Play، يمكنك إضافة الأسرار التالية في مستودع GitHub (`Settings` -> `Secrets and variables` -> `Actions`):

| اسم السر (Secret Name) | الوصف |
| :--- | :--- |
| `STORE_PASSWORD` | كلمة مرور مستودع المفاتيح (Keystore password) |
| `KEY_PASSWORD` | كلمة مرور مفتاح التوقيع (Key alias password) |
| `KEYSTORE_PATH` | مسار ملف المفتاح أو يتم فك تشفيره من base64 أثناء الـ CI |
